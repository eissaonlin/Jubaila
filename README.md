# الجبيلة - المنظومة الذكية لإدارة المزرعة ومياه الري والإنتاج الحيواني 🌾💧🐄

تطبيق ويب تقدمي (Progressive Web Application) متكامل وخفيف الوزن، صُمم خصيصاً لإدارة المزارع وحساب دورات مياه الري تلقائياً، وتتبع النفقات والإيرادات، وإدارة سجلات الماشية والتحصينات والعِشار.

---

## 🌟 المميزات الرئيسية

### 1. 💰 رصيد الإيرادات المتبقي بإضاءة نيون (Neon Glow Balance)
* احتساب فوري وتلقائي لصافي الأرباح والإيرادات بعد خصم جميع المصروفات اليومية وتكاليف تشغيل المياه.
* تصميم عصري جذاب بإضاءة نيون زمردية متوهجة أعلى الشاشة الرئيسية.

### 2. 💧 احتساب آلي لمواعيد مياه الري والتنبيه المسبق
* **قاعدة التراجع الأسبوعي (6 ساعات):**
  * **دورة الخميس:** تبدأ من 10:30 صباحاً حتى 3:00 عصراً، وتتراجع 6 ساعات كل أسبوع (4:30 ص في الأسبوع التالي).
  * **دورة الأحد:** تبدأ من 10:00 مساءً حتى 2:00 صباحاً، وتتراجع 6 ساعات كل أسبوع (4:00 م في الأسبوع التالي).
* **عرض الموعد القادم مباشرة في الشاشة الرئيسية** مع عدّاد تنازلي حي بالساعات والدقائق.
* **تنبيه عاجل قبل الموعد بساعتين:** إشعار بصري وامض ونغمة تنبيه صوتية للاستعداد وتشغيل المحابس والمضخة.
* **جدول الشهر الكامل:** عرض كافة مواعيد الشهر مع إمكانية تعديل أي موعد وتسجيل كميات الاستهلاك (سولار / كهرباء) والمبلغ المالي وترحيله تلقائياً للمصروفات.

### 3. 💸 إدارة المصروفات والإيرادات اليومية
* تسجيل المعاملات باليوم، التاريخ، المبلغ، والتصنيف، والبيان التوضيحي.
* تصفية وفلترة متقدمة وبحث سريع وإحصائيات لأعلى بنود الصرف ومصادر الدخل.

### 4. 🐄 سجل القطيع، التحصينات والعِشار
* تصنيف دقيق لرؤوس الماشية:
  * **البقرة الأم**
  * **الشابة الكبيرة**
  * **الشابة الصغيرة**
  * **العجل الصغير**
* **احتساب آلي لموعد الولادة المتوقع** بمجرد إدخال تاريخ التلقيح (+ 283 يوماً) مع شريط تقدم الحمل بالأيام والنسبة المئوية.
* **حساب عمر العجل الصغير** تلقائياً بالأيام ومتابعة وزنه وتغذيته على السرسوب.
* **سجل التحصينات الشامل:** جدولة لقاحات الحمى القلاعية، حمى الوادي المتصدع، الجلد العقدي، التسمم الدموي والمعوي، وتجريع الطفيليات.

### 5. 📲 دعم التثبيت كتطبيق (PWA) والعمل بدون إنترنت
* إمكانية تثبيت البرنامج كأيقونة مستقلة على شاشة هواتف أندرويد وآيفون وأجهزة الكمبيوتر.
* يعمل بدون الحاجة لاتصال بالإنترنت مع حفظ كافة البيانات محلياً (LocalStorage) مع ميزة التصدير والاستعادة (JSON Backup).

## 🚀 كيفية الرفع والتشغيل على GitHub

### الطريقة الأولى: الرفع المباشر عبر متصفح الويب (الأسهل والأسرع)
1. افتح حسابك على [GitHub](https://github.com) وأنشئ مستودعاً جديداً (New Repository) باسم `al-jubaila`.
2. اختر أن يكون المستودع عاماً (**Public**).
3. انقر على **"uploading an existing file"** واسحب ملف `index.html` و `README.md`.
4. اضغط على **"Commit changes"**.

### تفعيل رابط الموقع مجاناً عبر (GitHub Pages):
1. ادخل إلى إعدادات المستودع (**Settings**).
2. من القائمة الجانبية، اختر **Pages**.
3. تحت قسم **Build and deployment**، اختر الفرع **main** أو **master** واضغط **Save**.
4. خلال دقيقة، سيظهر لك رابط الموقع المباشر (مثل: `https://username.github.io/al-jubaila/`) لفتحه واستخدامه من أي هاتف أو جهاز فوراً!

## ملاحظات التثبيت (PWA)
- ارفع جميع ملفات المشروع معاً في نفس المجلد: `index.html` و`manifest.json` و`sw.js` وأيقونتي `icon-192.png` و`icon-512.png`.
- يجب تشغيل الموقع عبر HTTPS (مثل GitHub Pages) حتى يعمل التثبيت وService Worker.
- بعد فتح الموقع مرة أولى، استخدم زر «تثبيت البرنامج» أو قائمة المتصفح لإضافته إلى الجهاز.
- البيانات تبقى محفوظة محلياً في المتصفح عبر LocalStorage؛ احفظ نسخة JSON احتياطية دورياً.
- تنبيه: الواجهة تعتمد على Tailwind وGoogle Fonts من الإنترنت؛ قد لا تظهر التنسيقات والخطوط كاملة عند انقطاع الإنترنت لأول مرة أو إذا لم تكن مواردها مخزنة مؤقتاً.


## ملفات التثبيت والعمل كتطبيق PWA
ارفع الملفات التالية معاً في جذر مستودع GitHub:
- `index.html`
- `manifest.json`
- `sw.js`
- `icon-192.png`
- `icon-512.png`

بعد تفعيل GitHub Pages وفتح الموقع عبر HTTPS:
- Android: افتح الموقع في Chrome ثم اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- Windows: افتح الموقع في Chrome أو Edge، ثم اختر أيقونة التثبيت بجوار شريط العنوان أو من قائمة المتصفح.
- iPhone/iPad: افتح الموقع في Safari ثم «مشاركة» ثم «إضافة إلى الشاشة الرئيسية».

ملاحظة: يحفظ التطبيق بياناته محلياً على الجهاز؛ احتفظ بنسخ JSON دورية. بعض الخطوط والتنسيقات المحملة من الإنترنت قد لا تتوفر عند أول تشغيل دون اتصال.

## إعداد النسخ السحابي عبر Supabase
1. افتح `SUPABASE_SETUP.sql` وانسخ أوامر SQL إلى SQL Editor في مشروع Supabase ثم نفّذها.
2. من Authentication أنشئ مستخدماً (بريد إلكتروني وكلمة مرور) وفعّل تأكيد البريد أو عطّله حسب إعداداتك.
3. افتح المنظومة واضغط أيقونة ⚙️ ثم أدخل Project URL ومفتاح anon/publishable من إعدادات API.
4. احفظ بيانات الربط، ثم سجّل الدخول بحساب Supabase. استخدم «رفع نسخة إلى السحابة» أو «استعادة من السحابة».
5. كل مستخدم يخزن نسخة منفصلة محمية بسياسات RLS. لا تستخدم مفتاح `service_role` داخل المتصفح.

## تيليجرام
زر المشاركة الحالي يجهّز ملف JSON ويستدعي مشاركة النظام لاختيار Telegram. الإرسال الآلي إلى بوت تيليجرام غير مفعّل عمداً من المتصفح؛ يتطلب Supabase Edge Function تحفظ Bot Token كـ Secret حتى لا يظهر للمستخدمين.

## التحكم التفصيلي في الإعدادات والصلاحيات
- من أيقونة ⚙️ افتح «التحكم التفصيلي في الأقسام والبنود».
- لكل قسم يمكن تشغيل/إيقاف ظهوره، وتحديد السماح بالإضافة والتعديل والحذف.
- افتح «إعدادات البنود والحقول» داخل القسم للتحكم في ظهور كل حقل وتفعيله وجعله إلزامياً.
- وضع «مستخدم» يطبق قيود الواجهة على هذا الجهاز، ووضع «مدير النظام» يعرض جميع العمليات.
- إعدادات التحكم تحفظ محلياً في المتصفح ولا تؤثر على البيانات المخزنة. وهي ليست نظام صلاحيات متعدد المستخدمين آمناً على الخادم؛ لتفعيل صلاحيات حقيقية لكل حساب يجب إضافة جدول أدوار وسياسات RLS مخصصة في Supabase وربطها بحسابات المستخدمين.
